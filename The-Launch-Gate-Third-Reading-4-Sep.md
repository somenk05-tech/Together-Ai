## BLOCKERS (must close before any public door opens) — all four CLOSED in the tree, 4 Sep

## What is solid — and should be protected

Auth is well built (argon2, denylist, lockout, hashed single-use reset codes, Turnstile fail-closed, JWT re-reads the row every request, WS handshake re-checked every 60 s). Route exposure, query scoping, unbounded reads, wallet pricing, moderation reach and route reach are all **structural specs that fail the build**, and they held: no unscoped IDOR was found across 47 controllers. Private objects (health, drive, dating, KYC, CV, snaps) live in a separate bucket behind short signed links; dating photos are proxied per viewer and re-authorised per fetch. Snaps compute every deadline server-side and are unrecoverable after spend. Message authorisation is one gate. Wallet arithmetic is conditional-decrement with idempotency keys and race specs. Consent for health data is a single reader and PHI purge is model-complete. Nutrition's hard safety gates measure zero. The deploy pipeline refuses `db push`, 106 migrations all carry SQL and match the schema. Ten design ratchets and 1,317 web tests are green on the real tree. This is a codebase whose invariants are written as tests; the findings above are gaps between rooms, not rot inside them.
